# 排队消息与引导 UI 完善

本轮参考本地 `ZCode/packages/ui/src/v4/ConversationQueuePanel.tsx` 的交互布局，并根据 OneLab 现有 SolidJS 组件和主题重新实现。采用紧贴输入框的队列卡片；每条消息直接显示 Steer / 引导、编辑和删除按钮，更多菜单保留排序及暂停/恢复入口。单条消息隐藏重复标题，多条消息显示数量，附件与上下文提示继续保留，模型设置可在正文提示及编辑态查看。

左侧手柄支持鼠标、触摸和方向键排序。拖动超过 6px 才开始移动，显示插入位置；长队列在边缘自动滚动，速度不受屏幕刷新率影响。松开后使用原有持久队列的 `move` 操作保存实际执行顺序，不创建新消息。Escape、拖出队列、丢失指针捕获、窗口失焦、会话切换或队列版本变化均会取消手势。等待发送或编辑期间禁止拖动。原生浏览器提交时会暂时禁用按钮，因此保存成功后在未转移到其他控件的前提下恢复手柄焦点，支持连续键盘排序。

UI 沿用主题颜色、圆角、图标和焦点样式；窄会话列将操作放到下一行，长队列内部滚动。减少动态效果偏好会关闭新增颜色过渡。没有引入新的拖动库，没有改变消息默认排队、快捷键引导、后端幂等性和权限逻辑。
