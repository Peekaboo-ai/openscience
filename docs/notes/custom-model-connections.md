# 自定义 API 多模型连接

Models 页新增 Custom API connections，沿用现有设置卡片、字体、颜色变量、Button 和 Checkbox。
支持多个 OpenAI 兼容 Chat Completions 网关，按 API URL 和 Key 获取模型目录、搜索、多选、
手动填写 ID、调整上下文/输出限制、编辑和删除。

## 实现边界

- `CustomConnections` 将元数据写入全局 provider 配置，将密钥单独写入现有 Auth 存储。
  配置使用独立 UUID，不覆盖内置供应商。列表只返回 hasKey。
- 发现请求有 15 秒超时、2 MB 响应上限、2,000 模型上限；禁止带密钥跟随重定向，
  对上游失败返回不含原始响应内容的提示。
- 同一端点可保留密钥；变更端点必须明确输入密钥。保存精确替换选中模型。
  修改操作使用跨进程文件锁串行化，并在配置或凭据写入失败时尝试恢复原值。
- 配置更新刷新供应商和项目配置缓存，不销毁正在使用的项目实例。
- 对话菜单不再补入未连接的推荐项；目录元数据本身不代表已连接。
  自定义连接的模型身份保留大小写及完整路径，避免同名部署被合并。
- 配置和发现不保证第三方账号对每个模型均有推理权限。界面支持文本输入/输出及工具调用；
  其他协议、逐模型能力和价格可通过已有配置文件机制设置。
